💻 Cloud Computing Overview

      Cloud computing is the delivery of IT resources (like servers, storage, analytics, databases, networking, and security) over the internet, often with a pay-as-you-go pricing model. 🌐💸

🌟 AWS Cloud Computing

AWS (Amazon Web Services) is a secure cloud platform offering various cloud services like:

      Servers 🖥️
      
      Storage 📂
      
      Analytics 📊
      
      Databases 🗄️
      
      Networking 🌐

Security 🔒

    🔌 Three Types of Cloud Services
    
    SaaS (Software as a Service) 🖥️
    
    Provides software tools to clients.
    
    Example: Zoom 📞, SalesForce 🧑‍💼
    
    PaaS (Platform as a Service) 🛠️
    
    Provides a platform for building and managing applications.
    
    Example: Google Search Engine 🔍
    
    IaaS (Infrastructure as a Service) 🏗️
    
    Provides virtualized computing resources like servers.
    
    Example: AWS, Azure, Google Cloud 🌥️

💡 EC2 (Elastic Compute Cloud)

    EC2 is essentially a virtual machine (or server) in the cloud. It’s easy to scale and extend as needed. 🚀

🔑 AWS Account Creation Steps

      Open Gmail 📧
      
      Find and open the AWS course invitation email.
      
      Click on “Get Started”.

Create My Account 📝

    On the sign-up page, click “Create My Account”.
    
    Select your time zone (e.g., India Standard Time 05:30+).
    
    Set Your Password 🔐
    
    Set a password (use the same one as your Gmail for easy access).
    
    Go to Account Settings and finalize.

Log Out 🚪

    Once done, go to your Account Settings and click Log Out.
